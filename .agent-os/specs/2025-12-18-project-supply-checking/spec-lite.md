# Project Supply Checking - Lite Summary

Allow users to verify they have all required supplies for a project by comparing project item requirements against available inventory, identifying missing or insufficient items before starting work.

## Key Points
- View all items required for a project with their supply status
- Compare required quantities against available inventory
- Identify missing or insufficient supplies with clear visual indicators
- Provide supply gap summary showing what's needed to start the project
- Extend GraphQL project queries to include supply check data
